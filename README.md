# Blueprint Terminal — Developer Tools Collection

> A vintage blueprint-styled toolkit for modern developers.

**Blueprint Terminal** is a beautifully designed collection of essential developer utilities wrapped in a unique vintage blueprint aesthetic.

## ✨ Tools Included

- 🔧 **JSON Formatter & Validator** — format, minify, and validate JSON
- 🔢 **Base64 Encoder/Decoder** — text & file encoding with Unicode support
- 🧰 **Developer Essentials** — timestamps, hashes, URL encoding, regex tester & more

## 🎨 Design

- Vintage blueprint/technical-drawing theme
- Monospace typography with terminal vibes
- Smooth dark-mode aesthetic
- Fully responsive

## 🛠️ Built With

- Pure HTML5 + CSS3 + JavaScript
- Zero dependencies
